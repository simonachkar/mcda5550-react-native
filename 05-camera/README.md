# Using the device's Camera and Media Library 📸

This app is a practical example of how to use the device's camera and media library in React Native. It allows users to take pictures, and share them using other apps.

## Features

- **Take Photos**: Use your device's camera to capture pictures.
- **Share Photos**: Share your photos using `expo-sharing`.
- **Simple Navigation**: Showcases Drawer navigation, taking the user to another screen.

## Getting Started

To run the Camera App, follow these steps:

1. Navigate to the project directory.
1. Run `npm install` to install the necessary dependencies.
1. Start the app with `npx expo start` or `npm start`
